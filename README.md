# تبدیل گفتار به متن

یک ابزار ساده فارسی برای تبدیل گفتار به متن در مرورگر.

## امکانات
- تشخیص گفتار فارسی و انگلیسی
- تبدیل زنده گفتار به متن
- کپی متن
- پاک کردن متن
- انتخاب فایل صوتی و پخش آن هم‌زمان با تشخیص گفتار
- طراحی واکنش‌گرا با فونت Vazirmatn
- پردازش صدا در مرورگر

## اجرا
فایل اصلی پروژه `index.html` است و برای اجرا به سرور یا GitHub Pages نیاز دارد.

> قابلیت Speech Recognition به پشتیبانی مرورگر و اجازه دسترسی به میکروفون وابسته است.
